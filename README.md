# Spare Parts Desk

A full-stack spare parts inventory management and decision-support application designed to help businesses monitor inventory, identify stockout risks, and make smarter purchasing decisions.

## Features

* **Inventory Management:** View and manage spare parts inventory.
* **Stock Monitoring:** Identify low-stock and out-of-stock items.
* **Demand Estimation:** Estimate future stock requirements using historical sales data.
* **Reorder Recommendations:** Help determine when parts need replenishment.
* **Supplier Management:** Organize supplier information and lead times.
* **Purchase Order Tracking:** Review purchase order data and supplier delays.
* **Data-Driven Insights:** Use product, inventory, and sales datasets to support decisions.

## Technology Stack

* **Backend:** Python
* **Frontend:** HTML, CSS, JavaScript
* **Data Sources:** CSV datasets
* **Version Control:** Git and GitHub
